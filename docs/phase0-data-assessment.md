## 5. خطة النقل المقترحة (المرحلتان 1–3)
1. `legacy.raw` (المجموعات كما هي، **بدون** حقول كلمات المرور).
2. الأشخاص بالرقم الوظيفي مفتاحاً، والقومي المكرر في قائمة استثناءات.
3. الدورة + المقاعد + الاجتماعات + القرارات.
4. الشيكات ← قيود (حسب النوع على الدليل أعلاه)، والسلف غير المسوّاة (7) أرصدة عُهد افتتاحية.
5. المزايا الثلاثة (member_benefits + board_benefits + منح الشيكات) ← سجل واحد مع منع التكرار بالمرجع.
6. **تقرير مطابقة:** رصيد الدورة الافتتاحي + الإيداعات − الشيكات = الرصيد الدفتري، ويُطابَق مع آخر كشف بنك يقدمه المستخدم.

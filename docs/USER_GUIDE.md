# دليل الاستخدام — منصة النقابة

الرابط: https://nekaba-erp.vercel.app — يعمل من الموبايل مباشرة.

**ثبّته كتطبيق:** أندرويد (كروم): زر «تثبيت» في «أنشطتي» أو قائمة ⋮ ← «تثبيت التطبيق». آيفون (Safari): زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية».

## الدخول
| مين | إزاي |
|---|---|
| العضو / الموظف | تبويب «أنا عضو / موظف»: الرقم الوظيفي + آخر 4 أرقام من الرقم القومي (أو رقم الموبايل المسجّل كامل) |
| الإدارة | تبويب «الإدارة»: اسم المستخدم وكلمة المرور (أول مرة لازم تغيّرها) |

5 محاولات غلط ⇒ إيقاف الدخول مؤقتاً.

## العضو
- **أنشطتي:** الصفحة الرئيسية. فيها حالة الاستحقاق (عضو النقابة العامة يستحق الدعم والمنح) ونسبة اكتمال الملف.
- **ملفي / أسرتي:** راجع بياناتك وضيف أفراد أسرتك. التعديل على البيانات الرسمية بيروح «طلب تعديل» للإدارة تراجعه.
- **استفاداتي:** كل ما استفدت به من النقابة (منح، دعم، بدلات، توفير الكتب…).
- **الرحلات والفعاليات والإفطار:** احجز لك ولأسرتك ومرافقيك. ادفع قبل المهلة وإلا الحجز يسقط ويروح للمنتظرين. الإلغاء متاح بنسبة استرداد حسب المدة المتبقية (مكتوبة في الحجز). لو النشاط مجاني الحجز يتأكد فوراً.
- **المصايف:** قدّم في فترة التقديم ورتّب تفضيلاتك (الفوج، والمصيف ونوع الوحدة لو حابب). بعد غلق التقديم يتم التوزيع (أسبقية أو قرعة أو أولوية لمن لم يستفد). لو اتقبلت ادفع في المهلة. لو احتياطي هتتصعّد تلقائياً لو حد اعتذر. تقدر تعتذر أو تطلب تبديل (فوج/وحدة/تبادل مع عضو تاني بموافقته). نتيجة القرعة قابلة للتحقق من البذرة المعلنة.
- **المنح والمناسبات:** زواج (العضو والأبناء) 300 · وفاة الأب/الأم/الأبناء 300 · وفاة الزوج/الزوجة 500. اختار النوع وتاريخ الواقعة والمستفيد، وسلّم أصل المستندات للمكتب. تابع الحالة: مقدَّم ← مستوفى ← معتمد ← مصروف.
- **الأجهزة / العمرة والحج:** خدمة إعلان وحجز فقط — احجز الصنف/الباقة (تقسيط أو كاش، وعدد المسافرين للعمرة)، والسداد يتم مع المورد/شركة السياحة مباشرة.

## الإشعارات 🔔
الجرس في أعلى الشاشة عليه عدد الجديد: قبولك في مصيف، تأكيد حجز، اعتماد منحة، فتح حجز نشاط جديد… وللمسئولين «مهام مستنياك» (طلبات تنتظر مراجعتهم). فتح الصفحة يعلّم الكل مقروء.

## مدير المنظومة (SYS_ADMIN)
له **كل الصلاحيات**: الأعضاء والطلبات، المجلس، المالية، المزايا، الأنشطة، المصايف، المنح (مراجعة واعتماد وصرف)، الأجهزة والعمرة، التقارير، القوائم.

## أمين الصندوق (TREASURER)
- **المالية:** الملخص، الشيكات (صرف شيك بقرار المجلس)، المقبوضات، ميزان المراجعة، القيود (لا تُعدَّل — العكس فقط).
- **تسوية العهد:** من صفحة الشيك ← «تسوية العهدة» بالمستندات؛ المتبقي يُرد أو يُورَّد أو يُرحَّل.
- **التحصيل:** «تحصيل» على حجز رحلة أو طلب مصيف ⇒ إيصال وقيد. محاضر تسليم واستلام وحدات المصايف (التأمين يُحصَّل ويُرد أو يُخصم).
- **صرف المنح المعتمدة:** «صرف شيك» ⇒ القيد والميزة في سجل المزايا تلقائياً.

## مسئول الرحلات والمصايف (TRIPS_OFFICER)
- **الأنشطة:** «+ نشاط جديد» (النوع: رحلة / إفطار / فعالية…، الأسعار لكل فئة: كامل وللمستحق، شروط الاسترداد، قرار المجلس) ← فتح الحجز ← المقاعد بالأسبقية ← المشرفون ← الإقفال بعد النشاط (الدعم يتسجل في المزايا).
- **المصايف:** «+ موسم جديد» (الأفواج والوحدات سطر لكل واحد) ← فتح التقديم ← قفل التقديم ← التوزيع (القرعة تحتاج بذرة معلنة) ← اعتماد طلبات التبديل ← الإقفال بعد آخر فوج.

## مسئول الأجهزة (DEVICES_OFFICER)
- «+ عرض جديد» واختار النوع (أجهزة / عمرة / حج)، والأصناف/الباقات سطر لكل واحد ← فتح الحجز ← «الحجوزات»: تأكيد ← اتسلّم (أو رفض بسبب). لا يوجد أي قيد مالي.

## عضو مجلس الإدارة (BOARD) / المراجع (AUDITOR)
- **المجلس:** الدورات والمقاعد والاجتماعات والقرارات.
- **مراجعة مستندات المنح** (عضو المجلس).
- **التقارير الشاملة:** اختار السنة ← عرض ← طباعة.

## قواعد عامة
- الاستحقاق دائماً بالحالة في **تاريخ العملية**: النقابة العامة + نشط. النقابة المستقلة تشارك بالسعر الكامل بلا دعم ولا منح.
- كل عملية مالية = قيد متوازن بمستند مرقّم على الخادم؛ لا حذف — عكس بقيد.
- كل تعديل مسجّل في سجل التدقيق باسم من قام به.
